Settings

Theme

Click a theme to try it right now. The choice is saved in this browser only, for now (not on the server). Themes also restyle the terminal UI.

Fonts

Fonts are bundled with Judas, so they also work on phones and tablets. The choice overrides the theme and is saved in this browser only.

Companion

A small pixel buddy that reacts while Judas works. It only moves a little and stops when this tab is hidden.

Location

Lets Judas know where you are, for questions like what is open near me. Off until you turn it on; turning it on asks this browser for permission. While on, this page sends your position when it changes and every few minutes while it is visible. The server keeps only the latest position, in memory, and forgets it on restart or when you turn this off.

Model

Judas loads one model at a time, shared by every agent. Switching saves the choice and restarts the daemon so the new model loads; running chats are interrupted.

Swarm

Swarm cores

CPU threads for the swarm instance (small model, bulk jobs). Applied live, no restart; saved in its own config. Pinning keeps it on whole physical cores of one CCD first, away from the rest of the machine.
